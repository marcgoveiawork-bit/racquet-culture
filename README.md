# Racquet Culture

The community web app for Racquet Culture, Goa's padel and pickleball club.
Play. Recover. Repeat.

- Create an account with email, a username and a password; sign in with email
- Player profiles: photo or avatar, sports, hand, invites, times, court side
- A level check for padel (0.5 to 7) and pickleball (1.0 to 5.5+)
- Log scores; levels move fairly based on partner and opponent levels
- Beginner, Intermediate and Pro rankings for each sport

Setup and how the rankings work: see [SETUP.md](SETUP.md).
